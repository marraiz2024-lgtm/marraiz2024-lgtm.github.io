# Medición y ajuste

Cierra el circuito. Sin esta etapa el calendario se llena por intuición. Mercedes publica a mano, así que las cifras las copia ella desde las analíticas nativas de cada app. No inventes cifras ni compares con promedios del sector sin una fuente concreta.

## Qué se registra por pieza

Se copia de las analíticas de cada app, a los 3 días y a los 7 días de publicar.

| Campo | Nota |
|---|---|
| id de la ficha, serie, tipo, nivel, formato | Vienen de la ficha |
| Plataforma, fecha y hora | |
| Alcance o visualizaciones | El que ofrezca cada app |
| Interacciones: guardados, compartidos, comentarios, me gusta | Los guardados y compartidos pesan más que los me gusta para contenido educativo (criterio mío, no una norma de las plataformas) |
| Retención o porcentaje visto (video) | |
| Clics al link en bio, si se mide | |
| Herramienta y protagonista (avatar real, Mechita, B-roll) | Para comparar sin mezclar |

Guarda el registro como una tabla en Notion (nueva vista en el calendario o campos nuevos) o como hoja de cálculo. Propón la estructura y deja que Mercedes elija el lugar.

## Análisis

Con al menos 8 a 10 piezas registradas, compara por:

1. Serie contra serie (¿Cómo se dice?, No digas... Di..., verbos, Mechita, B-roll).
2. Protagonista (avatar real frente a Mechita frente a sin personaje).
3. Nivel (beginner frente a intermedio, para validar la mezcla 60/40).
4. Horario y plataforma.
5. Tipo de CTA (bio frente a comentarios), para cerrar la decisión pendiente.

Con menos datos, señala que la muestra es insuficiente y no concluyas.

Señala siempre el sesgo posible: una pieza puede rendir por el tema, la hora o la suerte, no por el formato. Una diferencia pequeña entre dos piezas no es una conclusión.

## Salida

```
RESUMEN: periodo, piezas analizadas
LO QUE FUNCIONÓ: dato, pieza, hipótesis de por qué (marcada como hipótesis)
LO QUE NO: igual
DECISIONES: qué repetir, qué probar, qué dejar
AJUSTES AL CALENDARIO: cambios de horario, mezcla de series, CTA
IDEAS PARA EL BANCO: 3 a 5 ideas nuevas con tipo de entrada (alimentan `mmercedes-cadena`)
LÍMITES: qué dato falta para concluir
```

Las ideas nuevas entran al banco con Estado Idea en Notion.
